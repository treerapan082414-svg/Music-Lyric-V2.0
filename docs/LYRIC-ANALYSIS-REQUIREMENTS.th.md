# ข้อกำหนดเพิ่มเติม: วิเคราะห์เนื้อเพลง ตำแหน่งท่อนร้อง และ UI ที่ใช้ง่าย

ใช้เสริม MASTER PROMPT ต้นฉบับ โดยแยกสิ่งที่ทำได้จริงออกจากเป้าหมายของระยะถัดไป

## การวิเคราะห์เนื้อเพลง

- แยกบรรทัด ท่อน และป้ายกำกับ Verse/Pre-Chorus/Chorus/Bridge/Outro รองรับการระบุเอง ไม่เดาโครงสร้างเป็นข้อเท็จจริง
- วิเคราะห์จำนวนบรรทัด คำ ความซ้ำ และตรวจความถูกต้องของเวลา ใช้ตัวแยกคำหลายภาษาที่รองรับไทย
- แสดงเวลาติดลบ จบก่อนเริ่ม ท่อนซ้อน และช่วงที่เกินเพลง พร้อมทางแก้ไขที่พาผู้ใช้ไปยังท่อนนั้นได้
- การวิเคราะห์อารมณ์ ความหมาย สัมผัส หรือแปลภาษาในอนาคตต้องระบุวิธี/โมเดล ความไม่แน่นอน และไม่ใช้ข้อความตัวอย่างแทนผลจริง

## ความตรงของตำแหน่งร้อง

- เป้าหมายคือให้ผู้ใช้ตรวจและปรับจนตรงกับเพลงอ้างอิง ไม่ใช้คำรับประกัน "ตรง 100%" จากระบบอัตโนมัติโดยไม่มีหลักฐาน
- แยกที่มาของเวลา: นำเข้าจากไฟล์ / เสนอโดยอัลกอริทึม / ผู้ใช้แก้เอง โมเดลไม่พร้อมต้องแจ้ง และยังมี Manual Sync
- แสดง waveform และ playhead ที่ผูกกับเวลาเดียวกับเสียง รองรับแก้ IN/OUT ระดับมิลลิวินาที ย้าย/ปรับขอบบล็อก offset และฟังซ้ำก่อนจุดเริ่ม
- โหมดจับเวลาทีละท่อนใช้ Space บันทึกเวลาเริ่ม พร้อมคำอธิบายว่า Space จะเปลี่ยนหน้าที่และวิธีหยุดเพลง
- Forced Alignment ในอนาคตต้องใช้เสียงจริง เนื้อร้องอ้างอิง โมเดลที่ระบุเวอร์ชัน และ timestamp ระดับคำที่ตรวจแก้ได้ รองรับคำร้องซ้ำ/แอดลิบ/RAP/ท่อนเว้นเสียง ท่อนที่ไม่แน่ใจต้องถูกทำเครื่องหมาย ห้ามจัดเวลาตามความยาวข้อความแล้วเรียกว่าซิงก์สำเร็จ
- ประเมินด้วยเพลงที่ผู้ใช้มีสิทธิ์และ timestamp ที่ตรวจโดยมนุษย์ รายงานความคลาดเคลื่อน start/end เป็น ms และสัดส่วนท่อนที่ผ่านเกณฑ์ที่ตกลงกัน ห้ามรายงานคะแนน 100% จากการไม่มีข้อความแจ้งเตือน

## UI สำหรับผู้เริ่มต้น

- แสดงทางเดิน 4 ขั้น: เพิ่มเพลง → ใส่เนื้อร้อง → จับเวลาและตกแต่ง → ส่งออก
- หน้า Editor เปิดทำงานได้ทันที ไม่บังคับผ่าน Landing หรือสมัครสมาชิก
- แยกแท็บเนื้อเพลง/วิเคราะห์/ตกแต่ง ลดตัวเลือกที่ยังใช้ไม่ได้ และไม่มีปุ่มฟังก์ชันจำลอง
- ใช้ภาษาไทย กระชับ แสดงชื่อเพลง ระยะเวลา สถานะบันทึก และสถานะเวลาประมาณอย่างเห็นได้ชัด
- รองรับคีย์บอร์ด สถานะ focus, label ของช่องกรอก และจอมือถือ แจ้งข้อผิดพลาดจริงพร้อมวิธีแก้
- พรีวิวและ export ใช้ renderer เดียวกัน ไฟล์ต้องมีเสียงจริงและเล่นได้ ตรวจอย่างน้อยทั้ง 16:9 และ 9:16
